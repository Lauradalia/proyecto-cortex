# 🧠 CÓRTEX

**Rehabilitación cognitiva anti-IA**

## 📌 ¿Qué es CÓRTEX?
CÓRTEX es una aplicación móvil diseñada para combatir la atrofia del pensamiento crítico y resolutivo causada por la dependencia excesiva de la Inteligencia Artificial. En un mundo donde herramientas como ChatGPT o Copilot resuelven problemas de programación en segundos, los profesionales están perdiendo la capacidad de enfrentarse a problemas complejos por sí mismos.

No es una app para aprender a programar, sino un **gimnasio mental** para recuperar el músculo cognitivo.

## ⚙️ ¿Cómo funciona?
1. **Diagnóstico:** Detecta tu nivel de dependencia a la IA.
2. **Entrenamiento (La Sala de Apagón):** Un entorno aislado donde te enfrentas a problemas reales de código. La app bloquea el copiar/pegar y no da respuestas automáticas.
3. **Informe de Autonomía:** Un registro objetivo de tu capacidad para resolver problemas sin ayuda de la máquina.

## 🛠️ Stack Tecnológico
*   **Lenguaje:** Kotlin (Android)
*   **Interfaz:** XML (Android Views)
*   **Backend:** Firebase (Auth & Firestore)
*   **Motor de Ejecución:** API de Judge0 (Sandbox de código)
